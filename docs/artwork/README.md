# Plexo Clínico · Product artwork

These Portuguese concept studies are part of Cássio Caetano’s work on post-visit communication. The patient messages are fictional. [Try the bilingual inbox prototype](https://drcassiocaetano.github.io/plexo-clinical-ai-demo/).

| Selected original | Product question |
| --- | --- |
| [After the visit](./01-after-the-visit.png) | What happens when the appointment ends and questions keep coming? |
| [Patient messages](./02-patient-messages.png) | A result and a medication question can arrive through the same channel. Who reviews each one? |
| [Which requests need a physician?](./03-review.png) | How can the team tell which messages need medical judgment? |
| [Choosing the right owner](./04-routing.png) | How do we keep a clinical question visible among appointment confirmations and receipt requests? |
| [The physician’s role](./06-physician-role.png) | Which follow-up tasks can the front desk own? |
| [Physician review and sign-off](./plexo-post-03-voce-assina.png) | Who approves a document before a patient receives it? |
| [Open follow-up items](./plexo-post-06-pendencias.png) | How can a clinician tell that an expected result or a signature is still pending? |

The five carousel excerpts keep the numbering on the supplied originals. The last two images come from a separate series.
